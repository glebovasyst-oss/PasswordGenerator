Password Manager CLI
Простое CLI‑приложение на Python для хранения паролей с шифрованием. Данные хранятся в SQLite3, пароли шифруются через Fernet, мастер‑пароль проверяется по хешу SHA‑256.

Особенности
Шифрование паролей: используется Fernet (библиотека cryptography). Каждый пароль хранится в зашифрованном виде.
Защита мастер‑пароля: при первом запуске мастер‑пароль хешируется алгоритмом SHA‑256 и сохраняется в БД. При входе хеш сверяется.
Ключ шифрования: генерируется при первом запуске и сохраняется в файле .key в директории проекта. Без этого ключа (и корректного мастер‑пароля) расшифровка невозможна.
Локальное хранение: вся база (passwords.db) и ключ (.key) хранятся локально — нет передачи данных по сети.
Команды CLI:
add — добавить запись (название, логин, пароль).
get — получить и скопировать пароль по названию.
list — показать список записей (название + логин).
delete — удалить запись по названию.
new — сгенерировать случайный пароль и сохранить его как новую запись.
help — показать справку по командам.
exit — выйти из приложения.
Автосоздание структуры: при старте автоматически проверяются и создаются таблицы в БД, если их нет.
Безопасность ввода: мастер‑пароль вводится без отображения символов.
⚠️ Важно: если вы потеряете мастер‑пароль или удалите файл .key, восстановить пароли будет невозможно. Делайте резервные копии файлов passwords.db и .key.

Установка
Убедитесь, что установлен Python 3.8+ (проверьте командой python --version или python3 --version).
Установите зависимость:
bash
pip install cryptography
Сохраните код приложения в файл password_manager.py в отдельной папке.
Запустите приложение:
bash
python password_manager.py
При первом запуске программа попросит задать мастер‑пароль. После этого будут созданы:

passwords.db — база данных SQLite.
.key — файл с ключом шифрования Fernet.
Как пользоваться
Первый запуск
Запустите приложение:

bash
python password_manager.py
Программа запросит мастер‑пароль (символы не отображаются при вводе). После подтверждения пароль будет захеширован и сохранён в БД.

Последующие запуски
При каждом запуске программа запрашивает мастер‑пароль для входа. После успешного входа вы попадаете в интерактивный CLI.

Пример сессии:

text
Введите мастер-пароль:
> add
Название: Google
Логин: user@example.com
Пароль: my_secret_password
> list
[1] Google — user@example.com
> get Google
Пароль скопирован в буфер обмена.
> exit
Как копировать пароли
Команда get не просто выводит пароль в консоль, а автоматически копирует его в буфер обмена ОС. Это сделано, чтобы избежать случайного сохранения паролей в истории терминала.

Поддерживаемые ОС:

Windows: используется pyperclip (через win32clipboard или fallback).
macOS / Linux: используется xclip / xsel либо pyperclip с системными утилитами.
Если копирование не срабатывает, установите дополнительную зависимость:

bash
pip install pyperclip
В некоторых Linux‑системах дополнительно может понадобиться xclip:

bash
sudo apt-get install xclip   # Debian/Ubuntu
sudo dnf install xclip       # Fedora
После этого команда get <название> будет копировать пароль в буфер.

Резервное копирование
Чтобы перенести хранилище паролей на другой компьютер или сделать бэкап:

Закройте приложение.
Скопируйте файлы:
passwords.db
.key
На новой машине поместите эти файлы в папку с password_manager.py.
Запустите python password_manager.py и введите тот же мастер‑пароль.
❗ Никогда не передавайте .key и passwords.db по незащищённым каналам. Эти файлы дают доступ ко всем паролям при наличии мастер‑пароля.

Ограничения и рекомендации
Это не полноценный менеджер паролей для продакшена. Не храните здесь критически важные пароли без дополнительных мер защиты.
Пароли хранятся в памяти Python как строки во время работы — для максимальной безопасности в реальных проектах используют более строгие методы очистки памяти.
Смена мастер‑пароля не реализована: при смене потребуется перешифровать все записи.
